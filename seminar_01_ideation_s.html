Упражнение 1: направете първата си туристическа web страница

Цел: до края на упражнението да имате ясна туристическа идея, попълнен кратък e-business паспорт, папка с файл index.html и работеща web страница, която се отваря в браузър.

Не са нужни предварителни знания по програмиране. Работете стъпка по стъпка. Не прескачайте напред, ако предишната стъпка още не е завършена.

Стъпка 1. Опишете бизнеса си с едно изречение

Преди да правите сайт, трябва да е ясно за кого е бизнесът, какъв проблем решава и какво предлага.

Напишете:
„Моят туристически бизнес помага на … да … чрез …“

Пример: „Зелени пътеки България“ помага на хора, които искат активен уикенд сред природата, да откриват малки групови турове с местни водачи.

Проверка: можете ли да го обясните за около 30 секунди без думи като AI, cloud, приложение или платформа?

Стъпка 2. Изберете един конкретен клиент

Не пишете „всички туристи“. Изберете една основна група, за която ще правите първата версия.

ПолеКакво да напишете
Кой е клиентът?Напр. Мария, 34 г., София
Какво иска?Напр. активен уикенд без сложна организация
Какво я притеснява?Цена, трудност, условия, анулиране
Как търси?Google, Instagram, препоръки
Какво я кара да резервира?Ясна цена, снимки, дата, доверие

Резултат: една конкретна персона.

Стъпка 3. Направете една конкретна туристическа оферта

Изберете само една оферта и я опишете достатъчно ясно.

  • име на офертата;
  • място;
  • продължителност;
  • дата или период;
  • цена;
  • какво е включено;
  • какво не е включено;
  • ниво на трудност;
  • максимален брой участници;
  • какво трябва да направи клиентът след това.
Проверка: човек, който не е слушал курса, трябва да разбере какво купува без да задава много допълнителни въпроси.

Стъпка 4. Нарисувайте пътя на клиента

Запишете последователността:

Открива → Разглежда → Избира → Заявява → Потвърждава → Участва → Оценява

За всяка стъпка запишете: какво прави клиентът, какъв въпрос има и какво трябва да му даде бизнесът.

Стъпка 5. Превърнете нуждите във функции

За всяка стъпка от пътя на клиента запишете най-малката цифрова функция, която е нужна.

НуждаМинимална функция
Да види офертитеСтраница с оферти
Да разбере детайлитеСтраница на оферта
Да избере датаСписък със свободни дати
Да подаде заявкаКратка web форма
Да получи потвърждениеСъобщение/e-mail

Не добавяйте още: сложен AI, мобилно приложение, динамични цени или enterprise архитектура.

Стъпка 6. Направете прост бизнес модел

За една резервация запишете:

  • продажна цена;
  • приблизителни променливи разходи;
  • каква сума приблизително остава преди общите разходи.

Не търсете счетоводна точност. Целта е да видите икономическата логика.

Стъпка 7. Определете вашето MVP

Разделете функциите в три колони:

Трябва сегаПолезно послеНе сега
Начална страницаПотребителски профилМобилно приложение
ОфертаОнлайн плащанеСложна AI система
Форма за заявкаКалендарДинамично ценообразуване

Правило: ако не сте сигурни дали функцията е нужна сега, сложете я в „Полезно после“.

Стъпка 8. Попълнете e-business паспорта

Съберете всичко от предишните стъпки в една кратка спецификация:

  • име на бизнеса;
  • основен клиент;
  • проблем/желание;
  • основно предложение;
  • първа оферта;
  • основен клиентски поток;
  • MVP функции;
  • приход;
  • основна метрика;
  • какво няма да правите в първата версия.
Проверка: дайте го на колега. Той трябва да може да каже: „За кого е?“, „Какво прави клиентът?“ и „Как ще разберем, че работи?“

Стъпка 9. Отворете VS Code

Използвайте Visual Studio Code, не Visual Studio.

  1. Ако имате VS Code Desktop — отворете него.
  2. Ако нямате право да инсталирате програми — отворете vscode.dev в Chrome или Edge.
  3. Помнете: VS Code е мястото, където пишете файла; браузърът е мястото, където виждате резултата.

Стъпка 10. Създайте проектна папка и index.html

  1. В Documents създайте папка zeleni-pateki-bulgaria.
  2. Във VS Code изберете File → Open Folder.
  3. Отворете папката.
  4. В левия Explorer създайте файл с име index.html.
  5. Проверете да не е index.html.txt.

Резултат: една папка + един празен файл index.html.

Стъпка 11. Напишете първия HTML

Копирайте кода по-долу в index.html.

Първа версия:
<!DOCTYPE html>
<html lang="bg">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Зелени пътеки България</title>
</head>
<body>
  <h1>Зелени пътеки България</h1>
  <p>Малки приключения сред природата, подбрани с грижа.</p>
  <h2>Нашата първа оферта</h2>
  <h3>Уикенд в Западните Родопи</h3>
  <p>Двудневно пешеходно преживяване за малка група.</p>
</body>
</html>
  1. Натиснете Ctrl+S.
  2. Намерете index.html във File Explorer.
  3. Кликнете два пъти върху файла.
  4. Той трябва да се отвори в браузър.
Ако виждате заглавието и текста: първата ви web страница работи.

Стъпка 12. Заменете примера с реална туристическа оферта

Заменете съдържанието между <body> и </body> с по-пълна версия:

<body>
  <header>
    <h1>Зелени пътеки България</h1>
    <p>Малки приключения сред природата, подбрани с грижа.</p>
  </header>

  <main>
    <section>
      <h2>Уикенд в Западните Родопи</h2>
      <p>Двудневно пешеходно преживяване за начинаещи туристи.</p>
      <ul>
        <li>Продължителност: 2 дни</li>
        <li>Група: до 10 участници</li>
        <li>Ниво: начинаещи</li>
        <li>Цена: 220 лв. на човек</li>
      </ul>
      <p><strong>Следваща дата:</strong> 12–13 септември</p>
      <a href="mailto:info@zeleni-pateki.example?subject=Запитване за Родопите">
        Изпрати запитване
      </a>
    </section>
  </main>

  <footer>
    <p>Учебен проект „Зелени пътеки България“</p>
  </footer>
</body>

После: Ctrl+S → върнете се в браузъра → Ctrl+R.

Стъпка 13. Добавете минимално CSS оформление

В <head>, точно преди </head>, добавете:

<style>
body {
  font-family: Arial, sans-serif;
  max-width: 900px;
  margin: 0 auto;
  padding: 24px;
  line-height: 1.6;
}

header {
  margin-bottom: 32px;
}

section {
  border: 1px solid #cccccc;
  border-radius: 12px;
  padding: 24px;
}

a {
  display: inline-block;
  margin-top: 12px;
  padding: 10px 16px;
  border: 1px solid currentColor;
  border-radius: 8px;
  text-decoration: none;
}
</style>

Отново: Ctrl+S → Ctrl+R.

Не се стремете към красив дизайн. Целта е да видите как CSS променя начина, по който изглежда HTML съдържанието.

Стъпка 14. Персонализирайте страницата

Сега променете примера така, че да е ваш:

  1. сменете името на бизнеса;
  2. сменете офертата;
  3. сменете цена и дата;
  4. добавете списък „Какво е включено“ с поне 3 елемента;
  5. добавете <h2>За нас</h2> и 2–3 изречения;
  6. променете поне едно CSS правило и вижте какво става.

Стъпка 15. Ако нещо не работи — проверете това

ПроблемКакво да направите
Файлът се отваря като текстПроверете дали е .html, не .txt; Open with → browser.
Кирилицата е страннаПроверете <meta charset="UTF-8">.
Промяната не се виждаCtrl+S във VS Code, после Ctrl+R в браузъра.
Линкът не работиПроверете href; mailto: е само временен учебен вариант.
В vscode.dev няма terminalНормално е. За terminal използвайте VS Code Desktop или Codespaces.

Стъпка 16. Финална проверка и предаване

Трябва да можете да покажете:

  • попълнен e-business паспорт;
  • папка на проекта;
  • файл index.html във VS Code;
  • работеща страница в браузър;
  • поне една промяна, направена от вас;
  • screenshot на страницата;
  • 3–5 изречения рефлексия: какво беше ново, какво не проработи от първия път и как го поправихте.
Последен тест: направете малка промяна във VS Code → Ctrl+S → върнете се в браузъра → Ctrl+R. Ако промяната се вижда, основната практическа цел е изпълнена.

Финален checklist

ПроверкаДа/Не
Имам конкретен клиент и туристическа оферта.
Имам попълнен e-business паспорт.
Имам проектна папка и index.html.
Страницата се отваря в браузър.
Кирилицата се вижда правилно.
Имам туристическа оферта със списък и линк за действие.
Добавил/а съм минимално CSS оформление.
Мога да направя Save → Refresh и да видя промяната.
Имам screenshot и кратка рефлексия.

Когато всички отговори са „Да“, Упражнение 1 е завършено.

Синтезирана постъпкова версия на материала за Упражнение 1. Запазени са задачите, примерите, кодът и критериите за завършеност от оригиналния учебен HTML материал.

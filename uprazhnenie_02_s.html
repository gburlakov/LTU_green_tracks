Упражнение 2: от първата web страница до интерактивен туристически сайт

Цел: да надградите работещия проект от Упражнение 1, като разделите HTML, CSS и JavaScript, добавите три туристически оферти, responsive дизайн, форма за заявка и първа интерактивна логика.

Важно: не започвайте от празен проект. Работете върху копие на работещата версия от Упражнение 1. Така винаги ще имате безопасна предишна версия.

Стъпка 1. Направете копие на проекта от Упражнение 1

  1. Намерете папката на проекта от предишното упражнение.
  2. Направете нейно копие.
  3. Преименувайте копието на zeleni-pateki-bulgaria-v2.
  4. Отворете новата папка във VS Code чрез File → Open Folder.
  5. Проверете, че вътре има старият index.html.
  6. Отворете страницата в browser и се уверете, че старата версия още работи.
Проверка: ако страницата от Упражнение 1 се вижда нормално, можете да продължите.

Стъпка 2. Създайте трите основни файла

Ще разделим проекта на три роли:

ФайлРоля
index.htmlструктура и съдържание
styles.cssвизуален дизайн
script.jsповедение и интерактивност
  1. В Explorer създайте styles.css.
  2. Създайте script.js.
  3. Създайте папка images.
Внимание: styles.css и style.css са различни имена. Пишете точно.

Стъпка 3. Свържете index.html със styles.css

Заменете началната част на index.html със следната структура:

<!doctype html>
<html lang="bg">
<head>
  <meta charset="utf-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1">
  <title>Зелени пътеки България</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>

</body>
</html>

Редът с viewport е важен за телефони, а <link> свързва HTML документа с CSS файла.

Стъпка 10. Добавете първата JavaScript логика

Поставете в script.js:

const form = document.getElementById("booking-form");
const result = document.getElementById("booking-result");

const tours = {
  rodopi: {
    name: "Уикенд в Родопите",
    price: 220
  },
  belogradchik: {
    name: "Вело уикенд край Белоградчик",
    price: 260
  },
  shabla: {
    name: "Наблюдение на птици край Шабла",
    price: 180
  }
};

form.addEventListener("submit", function (event) {
  event.preventDefault();

  if (!form.checkValidity()) {
    form.reportValidity();
    return;
  }

  const name = document.getElementById("name").value.trim();
  const email = document.getElementById("email").value.trim();
  const tourKey = document.getElementById("tour").value;
  const people = Number(document.getElementById("people").value);
  const date = document.getElementById("date").value;

  const tour = tours[tourKey];
  const total = tour.price * people;

  result.className = "result success";
  result.innerHTML = `
    <strong>Заявката е проверена.</strong><br>
    ${name}, избрали сте „${tour.name}“
    за ${people} участници.<br>
    Предпочитана дата: ${date}.<br>
    Ориентировъчна стойност: ${total} лв.<br>
    Потвърждение би било изпратено на ${email},
    но данните все още не напускат browser-а.
  `;
});

И в styles.css:

.result.success {
  margin-top: 20px;
  padding: 16px;
  background: #e8f6ed;
  border-left: 4px solid var(--green-2);
}
  1. Save и трите файла.
  2. Refresh.
  3. Попълнете тестови данни.
  4. Изберете оферта и брой участници.
  5. Натиснете „Провери заявката“.
Проверка: показаната сума трябва да е цена × брой участници.

Стъпка 11. Разберете какво направихте с JavaScript

ТерминКакво направихме
DOMНамерихме form и полета чрез document.getElementById(...).
EventРеагирахме на submit.
VariableЗапазихме name, email, people, date и tour.
ObjectСъбрахме имената и цените в tours.
ValidationПроверихме required, e-mail формат и min/max.
Template literalСглобихме резултат с ${...}.

Важно: данните не се изпращат към реален server и изчезват след Refresh. Това е очаквано за тази версия.

Стъпка 12. Използвайте Developer Tools при грешка

  1. Отворете сайта.
  2. Натиснете F12.
  3. В Elements намерете h1 и временно променете текста.
  4. Refresh — промяната ще изчезне, защото не сте редактирали source файла.
  5. Отворете Console и проверете за червени грешки.
ПроблемПроверете
Навигацията не мести страницатаСъвпадат ли href="#offers" и id="offers"?
Cards са една под друга на широк екранИма ли display:grid и правилен grid-template-columns?
Submit не прави нищоСвързан ли е script.js? Има ли грешка в Console?
JavaScript казва, че form е nullСъвпада ли booking-form в HTML и JS?
Цената е NaNИзползвате ли Number(...) и избрана ли е оферта?

Стъпка 13. Стартирайте local web server

Тази стъпка е за VS Code Desktop или GitHub Codespaces. Ако работите само във vscode.dev, може да я пропуснете.

  1. Изберете Terminal → New Terminal.
  2. Проверете, че terminal-ът е в папката zeleni-pateki-bulgaria-v2.
  3. Ако имате Python, изпълнете:
python -m http.server 8000
  1. В browser отворете http://localhost:8000.
  2. Проверете, че сайтът изглежда като преди.
  3. За да спрете server-а, натиснете Ctrl+C в terminal-а.

localhost означава вашия собствен компютър/development environment. Сайтът още не е публичен.

Стъпка 14. Направете пълен тест като турист

  1. Отворете началото на сайта.
  2. Натиснете „Разгледай офертите“.
  3. Проверете трите продукта.
  4. Намалете прозореца и вижте дали cards стават една под друга.
  5. Натиснете „Изпрати заявка“.
  6. Опитайте submit с празни полета — browser validation трябва да се включи.
  7. Попълнете тестови данни.
  8. Проверете дали ориентировъчната цена е правилна.
  9. Refresh — резултатът ще изчезне, защото още няма back end.
